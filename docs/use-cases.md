# Use Cases

NotifyLite isn't just a visual upgrade; it's a functional open source Windows utility for a wide variety of users.

## For Productivity Enthusiasts
Stay in the zone without distraction. By utilizing the "Stick to Icon" position, you can drag your notification center alternative to a secondary monitor or a corner where it won't cover your active work. Customize auto-dismiss times so alerts vanish exactly when you want them to.

## For Developers
Developers constantly receive build alerts, server notifications, and chat pings. Assign different `.wav` sounds to your IDE vs. your Slack app. Mute noisy background tasks entirely so you only get interrupted by what actually matters. 

## For Windows Customization Users
If you use tools like Rainmeter, TranslucentTB, or custom themes, the default Windows notification banner sticks out like a sore thumb. NotifyLite lets you perfectly match your desktop's aesthetic—down to the exact hex codes and corner radius.

## The Ultimate Alternative to Default Windows Notifications
If you have ever asked, "How do I change Windows notifications?" or "Can I replace Windows toast notifications?", NotifyLite is the definitive answer.

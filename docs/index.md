# NotifyLite — Open Source Windows Notification Replacement

**Replace boring default Windows notifications with beautiful customizable toast alerts, notification history, and app-level controls.**

[**Install Now**](installation.md) | [**View Features**](features.md) | [**GitHub Repository**](https://github.com/AfaqAhmad0/NotifyLite)

## The Ultimate Windows Notification Manager
Are you tired of the rigid, uncustomizable native Windows notification system? NotifyLite is an open source Windows utility that intercepts your notifications and renders them exactly how you want.

### Key Benefits
- **Full Customization:** Control colors, fonts, sizing, and position.
- **Never Miss an Alert:** Access a scrollable notification history widget.
- **Stay Focused:** Mute specific apps and customize notification sounds per app.
- **Productivity Boost:** Interact with toasts effortlessly or quickly dismiss them out of your way.

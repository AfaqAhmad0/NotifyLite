# Security Policy

## Supported Versions
Security updates are only applied to the latest major release of NotifyLite.

| Version | Supported          |
| ------- | ------------------ |
| 2.x.x   | :white_check_mark: |
| 1.x.x   | :x:                |

## Reporting a Vulnerability
If you discover a security vulnerability within NotifyLite, please do not disclose it publicly. Instead, submit a private vulnerability report via GitHub Security Advisories or send an email to the repository owner. We will triage and address the issue as soon as possible.
